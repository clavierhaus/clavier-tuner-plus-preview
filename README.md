# Clavier Tuner Plus: public preview

This repository holds the public preview builds of **Clavier Tuner Plus**, the experimental edition of the Clavier Tuner piano tuning app by Clavierhaus, Vienna. It contains releases only. The source of Plus is private. The engine underneath is the free Clavier Tuner, which is open source (Apache-2.0).

- **Download:** see [Releases](../../releases). Each release has a signed Android APK and its SHA-256.
- **iPhone and iPad:** through TestFlight. The link is in the latest release once Apple has reviewed the build.
- **Expiry:** each preview stops working after 31 December 2026.
- **Your data:** everything stays on the phone and nothing is sent. Uninstalling the app removes every piano and every tuning with it.
- **Feedback:** open an issue here.
